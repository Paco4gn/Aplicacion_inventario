INSTRUCCIONES PARA INSTALAR EL AGENTE DE INVENTARIO
====================================================

OBJETIVO
--------
Actualizar automáticamente en IT Inventario los datos técnicos de cada equipo Windows.

NECESITAS
---------
- La URL publicada de IT Inventario.
- El token privado INVENTORY_AGENT_TOKEN configurado en el alojamiento.
- El archivo scripts\collect-windows-inventory.ps1.

INSTALACIÓN
-----------
1. Copia collect-windows-inventory.ps1 al ordenador.
2. Abre PowerShell como administrador.
3. Ejecuta, sustituyendo la URL y el token:

powershell -ExecutionPolicy Bypass -File .\collect-windows-inventory.ps1 `
  -Install `
  -ApiUrl "https://URL-DEL-INVENTARIO" `
  -AgentToken "TOKEN-DEL-AGENTE" `
  -SerialNumber "PC001" `
  -Location "Oficina principal" `
  -IntervalDays 15 `
  -RunAtStartup

El número de serie puede omitirse para usar el de la BIOS o el nombre del equipo cuando la BIOS no ofrece uno válido.

DATOS QUE ACTUALIZA
-------------------
- Nombre, marca y modelo.
- Sistema operativo, IP y MAC.
- Procesador, RAM y almacenamiento.
- Fecha del último inventario.

En equipos ya existentes no sobrescribe ubicación, asignación, estado, notas manuales ni tipo de activo.

SEGURIDAD
---------
El token se guarda cifrado mediante la protección de credenciales de Windows en:

C:\ProgramData\ITInventario\agent.json

La tarea programada se llama:

IT Inventario - Inventario automatico
